# Asset drop-in locations

Add your own images here, then edit src/brand.js:

- logo: /assets/regulens-logo.svg (or PNG/WebP), square mark; displayed at 24 px.
- pipeline: /assets/evidence-pipeline.svg (or PNG/WebP), responsive wide illustration.
- pipelineAlt: a meaningful description of your illustration.

Paths are public URLs, without /public. Assets are optional; the existing icon and workflow remain usable without them. Keep labels and controls in the interface rather than embedding them in images. Do not place private documents or credentials in public/.

A favicon can be added here and linked from index.html when your final mark is ready.
